hub-backup

A private, single-user backup tool

hub-backup is a personal application used only by its owner, Steven Cardenas-Delgado. It stores encrypted backups of the owner's own files in the owner's own Google Drive.

What it accesses

It requests the drive.file permission, so it can only see and change files it created itself. It cannot read any other files in Google Drive.

Who can use it

Only the owner. It is not offered to the public and has no other users.
